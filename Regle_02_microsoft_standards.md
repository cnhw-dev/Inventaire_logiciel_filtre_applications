Règle 2 — Exclure les applications Microsoft standards
Exclure les applications et composantes Microsoft qui font partie du poste standard ou de l’environnement de base.
Exemples :
- Office 365 (Word, Excel, ...);
- Edge;
- OneDrive;
- OneNote;
- Teams;
- Whiteboard;
- Copilot (conserver Microsoft 365 Copilot);
- Exchange;
- Loop;
- Stream;
- Bing;
- composantes Microsoft Office;
- composantes Windows.

Ne pas exclure les applications Microsoft qui ne sont pas dans la suite office de base : 
Exemples : 
- Visio;
- Power BI;
- Visual Studio Code.

Conserver les lignes ambigues

Important - Méthode de traitement : 
Une liste distincte des applications correspondant à cette règle doit d'abord être générée, sans déplacement de lignes. Ensuite, chaque application de cette liste est traitée séparément, par secteur. L'onglet « Excluded Regle[numéro] » ([numéro] correspond au numéro de la règle) est créé une seule fois; toute ligne retirée d'un onglet de secteur doit s'y retrouver sans transformation (aucune perte de données).
